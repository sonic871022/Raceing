# 赛车游戏 - 加油！

## 游戏简介

赛车 - 加油！是一款 2-4 人的竞速游戏。玩家通过掷骰子"驾驶赛车"，通过技能卡互相博弈，同时要时刻关注自己的油量和车速，避免油量耗尽，或者超速冲出赛道。

经过弯道时要注意安全，在直道上尽情加速吧！

## 游戏流程

1. 游戏开始时玩家每人 2 张技能卡，3 格汽油（每一圈会消耗一格汽油，加速时也会消耗汽油）
2. 轮流掷骰子决定顺序
3. 每回合开始时玩家掷骰子决定前进格数，同时决定赛车速度
4. 每个弯道有车速限制，超速过弯会冲出赛道在弯心停留一回合
5. 先跑完 3 圈的玩家获胜
6. 中途如果油量耗尽就会退出比赛

## 技能卡

| 技能名 | 效果 |
|--------|------|
| 漂移过弯 | 经过弯道时打出，不受弯道限速影响 |
| 完美过弯 | 在红色刹车点停留时打出，骰子点数+N |
| 极限刹车 | 骰子点数 -1 ~ -3 |
| 精准加速 | 骰子点数 +1 ~ +2 |
| 氮气加速 | 本回合骰子 +2，不能与加油卡叠加 |
| 尾流跟随 | 停在前方玩家身后一格时打出，下回合跟着移动到身后第二格 |
| 极限卡位 | 与另一位选手同格时使用，让他倒退一格 |
| 加油卡 | 不用进站加油一格 |
| 过载浓烟 | 速度降至 3，无法使用加速技能 |
| 路障 | 本回合经过的格子上放置路障，下一个经过者骰子 -2 |
